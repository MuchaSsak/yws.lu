# Youth Work Synergy

A 3D landing page for a beautiful organization in Luxemburg 🏠💖

To view this application live, [click here](https://yws.lu/) 🚀

_Note: this project was very rushed due to having a lesser than a week deadline (and I had to do it in my free time). I didn't worry about clean code too much, however I think it is still acceptable. What matters is that the site looks beautiful :) Sorry for any bugs in advance!_

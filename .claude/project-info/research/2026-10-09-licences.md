# yws.lu licence audit (2026-10-09)

The owner's rule: every asset, library and copied component must be free for commercial use (OFL, Apache, MIT, BSD, ISC, CC0, or CC BY with the credit shown) or be the client's/owner's own work. An unknown licence is flagged.

Method: I opened every file listed below. For each npm package I read the `license` field and the LICENSE file in `node_modules`, using a node script over all 47 direct dependencies and all 461 installed packages. I parsed the JSON chunk of each `.glb` with a node script and pulled out its embedded textures to look at them. I checked upstream licences through their GitHub LICENSE files, the GitHub licence API, the vendors' licence pages and the Sketchfab API (`api.sketchfab.com/v3/models/<uid>`). Every source was checked on **2026-10-09**. This is a technical licence review, not legal advice.

Status labels: **OK** = allowed under the owner's rule. **OK-fix** = allowed, but a notice or credit is missing. **FLAG** = outside the owner's rule, or the licence or permission is unknown.

**Is the credits dialog complete and correct?** (`lib/dictionary.tsx` `creditsDescription`, EN lines 98-221 and FR from 721, opened from Footer → "See credits")

CC BY 4.0 §3(a)(1) requires: creator ✓, link to the material ✓ (short links), licence name and link ✓ (prefer `https://creativecommons.org/licenses/by/4.0/`), and an indication of modifications ✗. §3(a)(2) lets the credit be given "in any reasonable manner based on the medium", so a footer dialog is acceptable.

Gaps:
1. No "modified" note for `house.glb`. A pure format or compression change is a "technical modification" under §2(a)(4), which "never produces Adapted Material", and the CC FAQ says "It is not necessary to note trivial alterations". Writing "modified (optimised)" is still the safe, harmless choice and matches the owner's rule. For the bedroom, which has real content changes, the note is **mandatory**.
2. "Heart in Love" is listed but not used.
3. I confirmed `skfb.ly/oOAM6`. The other 4 short links answer HTTP 202 (Sketchfab bot protection), so a script could not resolve them. Their titles and authors match the API records. Replace them with the canonical URLs above, which are also embedded in the `.glb`s.
4. Optional: link the author names to their Sketchfab profiles.

Suggested wording: *"Cat House" (link) by Roman_Nilikovskii, CC BY 4.0 (link) — modified (optimised)*.

Sources: CC BY 4.0 legal code https://creativecommons.org/licenses/by/4.0/legalcode.txt; CC FAQ https://creativecommons.org/faq/. Both checked 2026-10-09.

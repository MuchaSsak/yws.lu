# Astro (how this site uses it)

> How the static Astro site is built, routed and hosted: the rules a change must keep. Versions and the stack
> decision live in [technologies](../technologies.md); URLs and locales in [i18n](../../site/i18n.md).

## Shape

| Piece | Where | Rule |
| --- | --- | --- |
| Output | `astro.config.mjs` | `output: "static"`, `trailingSlash: "always"`, `build.format: "directory"`, `compressHTML: true` (Astro 7's default `'jsx'` glues inline words together) [research: stack] |
| Pages | `src/pages/[locale]/index.astro`, `[locale]/[page].astro`, `index.astro` (root safety net), `404.astro` | every inner page comes from `pageStaticPaths()` in `src/lib/routes.ts`; never a hand-written path |
| Layout | `src/layouts/BaseLayout.astro` | the only `<head>`: title, description, robots, canonical, hreflang, OG/Twitter, font preload, skip link, header, footer, the in-view script |
| Data | `src/data/*.ts` | the organisation's facts, statistics and house pictures, typed, one source ([content model](../../content/content-model.md)) |
| Styles | `src/styles/global.css` | Tailwind 4 `@theme` tokens + the few component classes; tokens are AA-tested (`tokens.test.ts`) |
| Scripts | `<script>` in components, `src/scripts/*.ts` | bundled and deferred by Astro; each one starts after `load` + idle when it is decoration |
| Islands | `src/components/three/**` | React only for WebGL; mounted by a tiny loader, not `client:*` (see [three](three.md)) |

## Middleware

`src/middleware.ts` runs **once per page at build** (static output): it reads `params.locale`, sets `locals.locale`
and the Lingui context. No cookies, headers or `Accept-Language` exist at build time [research: stack § 1.3].

## Hosting (Vercel, no adapter)

- A static site needs no `@astrojs/vercel` [research: stack § 1.7]. What Astro can't do statically goes in
  `vercel.json`, **generated** by `scripts/vercel-config.ts` from `src/lib/routes.ts`: the `/` 307 by
  `Accept-Language`, every legacy 308, `trailingSlash: true`, cache and security headers. `bun run build` fails while
  the committed `vercel.json` is stale; `routes.test.ts` checks it too.
- Astro `redirects` and i18n root redirects are **meta-refresh pages without a status** in static output: never
  use them for SEO redirects.
- `vercel.json` sits at the **repo root** and sets `framework`, `installCommand` / `buildCommand` (`cd web && …`) and
  `outputDirectory` (`web/dist`), so the switch from the Next app needs no Vercel project-setting change
  ([technologies](../technologies.md) § Hosting) [assumption: confirm on the first preview].
- Node: `engines.node >=22.19.0` (Lingui 6, Lighthouse); Vercel then builds on 24.x [research: stack].

## Local preview = production behaviour

`bun run preview` runs `scripts/serve.mjs`: `dist/` with the same redirects (incl. the header condition), headers,
trailing-slash rule, brotli/gzip and `404.html` with a 404 status. Lighthouse, shots and e2e run against it
(port 4322), so local numbers include compression and real redirect chains. `astro preview` does none of that.

## Images

- Local images: `astro:assets` `<Image>`/`<Picture>` (`formats={["avif","webp"]}` for photos; `priority` only on a
  real LCP image). SVG passes through.
- No remote images: the house pictures (once a Supabase bucket) are repo assets in `src/assets/houses/`, listed in
  `src/data/houses.ts`; widths never exceed the source (`[400, 600, 800]` filtered by the file's width).
- Pre-rendered decoration (the background glow, posters) is generated by scripts in `scripts/` and committed to
  `public/` with its generator named in [assets](../../design/assets.md).

## Gotchas

- The Rust compiler rejects unclosed tags the JSX code got away with.
- `class:list` for conditional classes; `set:html` never with copy (escape is the default).
- A component `<script>` runs once per page even when the component is used twice: query all instances.
- Astro ≥ 7.2.8 only (AVIF RCE GHSA-26w7-cxv4-gfx2); sharp ≥ 0.35.5 [research: stack].
